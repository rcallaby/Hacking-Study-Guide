# Twitter OSINT

Twitter OSINT can be used by penetration testers to gather information about an organization or individual. This information can be used to identify vulnerabilities and weaknesses in the organization's security posture.

## How does Twitter OSINT work?

Twitter OSINT works by using various techniques to gather information from Twitter. Penetration testers can use tools to automate the process of gathering information, which can save time and improve the efficiency of the process.

The first step in Twitter OSINT is to identify the target organization or individual. This can be done by searching for keywords related to the organization or individual on Twitter. Once the target has been identified, the next step is to gather information about the target.

## Tools used in Twitter OSINT

There are several tools that can be used in Twitter OSINT. These tools can automate the process of gathering information and make it easier for penetration testers to analyze the data.

[Twint](https://github.com/twintproject/twint) - Twint is an advanced Twitter scraping tool that allows penetration testers to collect data from Twitter. It can be used to gather information such as tweets, user profiles, followers, and more.

[Followerwonk](https://followerwonk.com/) - Followerwonk is a Twitter analytics tool that can be used to analyze Twitter followers. It can be used to gather information such as the number of followers, location, and activity.

[twtData](https://twtdata.com/) - twtData keeps a free archive of X/Twitter trending topics by day for each country and city, useful for dating when a name or hashtag started trending. It also offers paid CSV exports of the follower and following lists of public accounts.

[TweetDeck](https://github.com/dimdenGD/OldTweetDeck) - TweetDeck is a Twitter management tool that can be used to manage multiple Twitter accounts. It can be used to gather information such as tweets, mentions, and messages.

[Social Searcher](https://www.social-searcher.com/) - Social Searcher is a social media search engine that can be used to search for information on social media platforms. It can be used to search for keywords related to the target organization or individual on Twitter.

[Twitonomy](https://www.twitonomy.com/) - It is basically a deep-dive analytics dashboard for X that breaks down everything from posting habits to who doesn't follow you back. It lets you easily track engagement metrics, inspect follower lists, and export data straight to Excel with a single click. Think of it as a handy shortcut for auditing an account's stats without having to crunch any numbers yourself.

[TruthNest](https://www.truthnest.com/) - TruthNest is an investigation-focused dashboard designed to evaluate whether a profile or post can actually be trusted. It analyzes a target's posting patterns, engagement style, and follower network to assign a credibility score and flag potential bot or troll behavior. Basically, it does the heavy lifting of sniffing out fake accounts, coordinated influence campaigns, and misinformation without you having to manually vet every tweet.
